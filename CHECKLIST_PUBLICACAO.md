# Checklist antes de divulgar o portfólio

- [ ] Abrir a página no desktop e no celular.
- [ ] Conferir se o tema claro/escuro funciona.
- [ ] Testar os quatro botões “Explorar projeto”.
- [ ] Testar “Copiar e-mail” e “Enviar e-mail”.
- [ ] Verificar o endereço real do LinkedIn e corrigir se necessário.
- [ ] Conferir links do GitHub e do Racha Franca.
- [ ] Inserir prints reais dos projetos, sem dados pessoais ou internos, quando disponíveis.
- [ ] Confirmar autorização para divulgar imagens de sistemas de terceiros ou clientes.
- [ ] Revisar textos e recursos realmente implementados em cada projeto.
- [ ] Confirmar que não há senhas, tokens, segredos ou arquivos `.env` no repositório.
- [ ] Verificar como a página aparece ao compartilhar o link (OG image opcional, ainda não configurada).
- [ ] Após publicação, testar o site usando o endereço HTTPS do GitHub Pages.
- [ ] Atualizar links do portfólio no GitHub e LinkedIn.
